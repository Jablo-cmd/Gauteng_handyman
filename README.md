# Gauteng Handyman Services — Website Concept

A responsive single-page website concept prepared by **Auris Nexus Technologies** as a private sales demonstration for Gauteng Handyman Services.

## Preview locally
Open `index.html` in a browser. No build step is required.

## Included
- Responsive mobile-first layout
- Service sections for plumbing, electrical work, carpentry, renovations, roofing and general handyman work
- Prominent click-to-WhatsApp enquiry links
- Quote form that prepares a WhatsApp message (no server submission or storage)
- Contact links for the business details found in public listings
- Basic SEO title, description and language metadata
- Accessible navigation controls and reduced-motion support

## Important before presenting or publishing
- This is an **unofficial concept**, not the business's approved or official website.
- Confirm all contact details, service descriptions, service areas and claims directly with the business.
- Images are illustrative stock photography from Unsplash, not photographs of the business's completed work. Confirm image licensing/usage and replace with the business's own authorised photos for production.
- The quote form opens WhatsApp and does not save enquiries to a database.
- Review all copy and service claims with the business before production launch.
- The demo ribbon is intentionally visible. Remove it only after the business authorises the site and the proposal is accepted.
